Polynomial conventions and reconstruction

In basis.json, variable indices 0–11 denote the twelve binomial-scaled amplitudes; indices 12–23 denote their conjugates. Each monomial is a sorted list of variable indices with a rational coefficient. Divide each channel by its corresponding basisScales value before applying the matrix. The positive component weights are reciprocal binomial coefficients. These finite data fully specify the proof.

The optional basis generator uses exact binary-form transvectants and SymPy. The independent verifier uses only Python’s standard library; no numerical solver or group-theoretic routine is required.
