Reproduce the checks

Run these from the website directory. The rational-bound verifier needs only Python's standard library. The exact witness checks require SymPy; the numerical state checks require NumPy.

python3 research/certificates/verify_certificates.py
python3 research/verify_exact_witnesses.py
python3 research/verify_minimum_s4.py
python3 scripts/verify_states.py --self-test data/catalogue.json

The checks cover 154 exact bound identities, 27 exact witness cases, three additional fourth-sector constructions and all 154 catalogue representatives. The bound verifier establishes inequalities; the witness verifiers establish attainment. Their combination proves optimality only when both values agree.

Numerical discovery used normalized complex Dicke coefficients, analytic-gradient L-BFGS-B searches, sparse-state searches and stationary refinement. The difficult cases were revisited with more than 1,000 random starts. Independent Pauli expectation checks agreed with reduced-purity inversion. The search code and saved run records are in research/search/; for example:

python3 research/search/optimize.py 11 6 min 1024

All catalogue optima are now proved. Earlier numerical searches and rational relaxation bounds are retained as historical discovery records; the linked exact certificates establish global optimality. Read the reproducibility notes.
